# Лабиринт сокровищ

**Лабиринт сокровищ** — это текстовая приключенческая игра в консоли на Python.  
Пользователь исследует лабиринт, собирает различные предметы, решает загадки, пытается избежать ловушек и добраться до сокровищницы.

Проект является результатом студенческого задания и демонстрирует:
- работу с состоянием игры без классов
- модульную архитектуру
- обработку пользовательского ввода
- случайные события и условия победы

---

## Установка

Проект использует **Poetry** для управления зависимостями.

```bash
poetry install

## Запуск игры
poetry run project

## Управление

Доступные команды в игре:  

- look — осмотреть текущую комнату  
- go <direction> — перейти в направлении (north, south, east, west)  
- north / south / east / west — короткие команды перемещения  
- take <item> — подобрать предмет  
- use <item> — использовать предмет  
- inventory — показать инвентарь  
- solve — попытаться решить загадку  
- help — показать список команд  
- quit — выйти из игры  

## Цель игры

Добраться до комнаты сокровищ и открыть сундук:  

- либо с помощью ключа  
- либо решив финальную загадку
